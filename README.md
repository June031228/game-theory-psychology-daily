# 每日博弈论与心理学

> 一个 30 天的内容系列：用**博弈论**看清人与人之间的策略互动，用**心理学**看清"理性"判断背后的认知偏差。两者结合，才能解释真实世界里那些"明明不该这样、却偏偏如此"的局面。
>
> 每天一篇，结构固定：
> - 📖 **名词解析** —— 一个核心概念，用大白话讲清定义与直觉
> - 💡 **知识点** —— 怎么用、为什么重要、常见误区
> - 📰 **真实案例** —— 优先采用真实新闻事件（附来源）
> - 🧩 **心理学连线** —— 把博弈论与心理学接起来
> - 🔗 **系列关联** —— 告诉你今天在整条脉络里的位置
